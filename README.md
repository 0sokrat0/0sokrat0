## Engineering lens

- A successful API response does not prove that the business state is correct.
- A service boundary should protect ownership, contracts, and failure modes — otherwise it is distributed spaghetti with a YAML addiction.
- Idempotency, retries, timeouts, and cancellation are system contracts, not middleware decoration.
- Tests should protect invariants and recovery paths, not inflate a coverage number.
- Simple, observable, reversible designs beat clever machinery that only one person can debug at 03:00.
